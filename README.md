# EPUB / TXT 繁簡轉換與字詞替換工具

純前端、單一 HTML 檔案的 EPUB / TXT 簡繁轉換工具，不需要伺服器，開啟後即可離線使用。

## 檔案結構

```
你的資料夾/
├── index.html          本工具主體
├── jszip.min.js         用來解壓縮／重新打包 EPUB（EPUB 本質上是 zip 檔）
└── opencc-js.min.js     簡繁轉換字典與引擎
```

三個檔案需放在同一層資料夾，`jszip.min.js` 與 `opencc-js.min.js` 直接複製
`epub-simplified-to-traditional-chinese` repo 裡原有的檔案即可。

## 使用方式

1. 用瀏覽器直接開啟 `index.html`（不需要安裝或啟動任何伺服器）
2. **拖曳或選擇檔案**
   - 拖曳／選擇多個獨立的 `.epub` / `.txt` 檔案
   - 或拖曳／選擇整個資料夾（支援多層子資料夾）
   - 選擇後**不會馬上轉換**，畫面會顯示已選取的檔案數量，等待你確認
3. **選擇 OpenCC 轉換模式**
   - `簡體 ➔ 臺灣正體（含常用詞彙修正）`：字體轉換 + 詞彙轉換（如「软件」➔「軟體」），預設選項
   - `簡體 ➔ 臺灣正體（僅字體）`：只轉換字形，不改詞彙（如「软件」➔「軟件」）
   - `簡體 ➔ 傳統繁體`：轉為通用繁體字形，不套用台灣用詞
   - `繁體 ➔ 簡體`
   - `不進行 OpenCC 轉換`：只執行下方的自訂字詞替換
4. **（選填）設定自訂字詞替換規則**：可新增多組「找字詞 → 換字詞」，會在 OpenCC 轉換**之後**套用，適合用來統一修正人名、專有名詞等
5. 都設定好之後，按下**「開始轉換並下載」**按鈕才會真正執行轉換
   - 獨立檔案模式 → 每個檔案各自轉換後單獨下載，**檔名與原始檔案完全相同**
   - 資料夾模式 → 轉換後打包成一個 zip 下載，**內部目錄結構與所有檔名都跟原始資料夾完全相同**，只有內容被轉換
6. 下方的黑色紀錄視窗會即時顯示每個檔案的處理進度與結果

## 運作原理

### EPUB 如何被轉換
EPUB 檔案本質上是一個 zip 壓縮檔，裡面包含 `mimetype`、`.opf`、`.ncx`、
`.html`/`.xhtml`（內文）、`.css`（樣式）等檔案。轉換流程：

1. 用 **JSZip** 把上傳的 `.epub` 讀取解壓縮成記憶體中的檔案清單
2. `mimetype` 檔案原封不動保留（EPUB 規範要求這個檔案不能被壓縮或修改）
3. 對 `.html / .xhtml / .htm / .ncx / .opf / .xml / .txt / .css` 這幾類文字檔案進行處理：
   - 先把 `href` / `src` 屬性裡的網址做 `decodeURIComponent` 還原，避免轉換過程誤傷百分號編碼的字元
   - 用 **OpenCC-JS** 執行實際的簡繁字元／詞彙轉換
   - 再套用使用者自訂的字詞替換規則
   - 自動把檔案內宣告的編碼（`<?xml encoding=...?>`、`<meta charset=...>`）修正為 `utf-8`
4. 圖片、字型等非文字類檔案原封不動複製，不做任何轉換
5. **檔名與資料夾名稱完全不變**，只有檔案內容被轉換（例如 `简体书名.epub` 轉換後檔名仍是 `简体书名.epub`，只有裡面的文字內容變成繁體）
6. 用 **JSZip** 把處理完的所有檔案重新打包回一個新的 `.epub`（zip）檔案

### TXT 如何被轉換
直接讀取純文字內容，依序套用 OpenCC 轉換與自訂字詞替換規則，輸出內容轉換後、
**檔名不變**的新 `.txt`。

### 資料夾模式
使用瀏覽器的檔案系統存取 API（`webkitGetAsEntry` / `webkitdirectory`）遞迴掃描
整個資料夾樹狀結構，逐一轉換裡面的 `.epub` / `.txt` 檔案內容，其餘檔案原樣保留，
**整個目錄結構與所有檔名都維持跟原始資料夾一模一樣**，最後用 JSZip 把整個結構
重新打包成一個 zip 檔案下載。

### 選擇後不會馬上轉換
選好檔案／資料夾之後，程式會先暫存起來，讓你有機會先設定好 OpenCC 模式、
新增字詞替換規則，確認都設定完成後再按下「開始轉換並下載」按鈕，才會真正
執行轉換與打包。

### 全程在瀏覽器端執行
所有處理（解壓縮、文字轉換、重新打包）都在你的瀏覽器記憶體中完成，
不會把檔案上傳到任何伺服器，適合處理私人書籍檔案。
